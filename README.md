# Maison Mistral

Boutique front-end de mobilier et d’objets pour la cuisine, réalisée en français avec Vite.

## Lancer le projet

Exécuter npm install, puis npm run dev.

## Parcours inclus

- Accueil, boutique, fiche produit, présentation de la maison et panier
- Commande en plusieurs pages : coordonnées, livraison, paiement fictif, récapitulatif et confirmation
- Panier et favoris conservés localement dans le navigateur

Cette maquette n’a pas de serveur. Elle ne collecte ni ne transmet les informations du formulaire, ne demande aucune donnée de carte bancaire, n’encaisse aucun paiement et ne crée aucune vraie commande. Les images de produits sont chargées depuis Unsplash.
